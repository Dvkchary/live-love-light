## 🚀 3 Ways to View and Use This Design

### Method 1: Instant Client Presentation (Recommended)
You and your client can view the complete design right away without needing a Figma account or software installation:
1. Double-click [`figma/index.html`](file:///c:/Users/vamsh/OneDrive/Desktop/candlesss/figma/index.html) to open it in **Google Chrome**, **Edge**, or **Safari**.
2. Features included in the viewer:
   - **Artboard Switcher:** Switch between Homepage, Product Studio, Brand Story, Mobile App, and Design System.
   - **Device Zoom & Pan:** Smooth zoom controls (Fit, 100%, + / -).
   - **Figma Specs Inspector:** Real-time CSS tokens, hex codes, typography scales, and dimensions.
   - **1-Click Copy:** Click any color swatch to copy its Hex code immediately.

---

### Method 2: Import Directly into Figma (Editable Vector Layers)
Figma natively parses SVG files into editable shapes, text layers, and auto-layout groups:
1. Open [Figma](https://figma.com) (in your browser or desktop app) and create a **New Design File**.
2. Open your local folder: `figma/screens/`.
3. Select any `.svg` file (e.g. `01_homepage_desktop_1440.svg`) and **drag and drop it onto the Figma canvas**.
4. **Result:** Figma creates a new frame with:
   - Vector shapes and rounded cards
   - Formatted text layers with fonts
   - Gradient fills and shadow effects
   - Grouped components ready for team editing!

---

### Method 3: Import Design Tokens into Figma
For design systems and developer handoff:
1. Install the **Tokens Studio for Figma** plugin in Figma.
2. Select **Load Tokens** and choose [`figma/tokens/design-tokens.json`](file:///c:/Users/vamsh/OneDrive/Desktop/candlesss/figma/tokens/design-tokens.json).
3. All colors, typography styles, shadows, and radii will automatically sync as reusable Figma styles.
